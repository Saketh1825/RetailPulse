    Why layer 3 doesn't trust layer 2
    
        
    The validator is a lexical check, not a formally verified SQL parser, so it is not assumed to be perfect. The test suite therefore also connects to PostgreSQL directly as the read-only role, with no application code in between, and confirms a raw DELETE is refused by the database and pg_sleep(2) is cancelled by the timeout.
